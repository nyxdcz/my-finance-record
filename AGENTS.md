# AGENTS.md

## User Preferences & Workflow Rules

- **Pre-execution Review Step**: Before executing modifications or applying major fixes, list and summarize the proposed changes/fixes first.
- **User Confirmation**: Wait for the user's explicit approval command (`proceed`) before executing final changes or pushing updates.
- **Version Bumping Rule**: Always update the application version and version history in `README.md`, `package.json`, and `index.html` for every update commit/release on the website.
