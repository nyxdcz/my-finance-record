# V13.0.1 MacBook & iPhone UI Validation

## Scope
- MacBook widths: 1440 × 900 and 1280 × 800.
- iPhone widths: 393 × 852 and narrow fallback at 360px.
- Pages: Dashboard, Income, Budget & Expenses, Paid Expenses, Projects, Project Payments, Reports, and Settings.

## Approved corrections
- Two-row iPhone top bar with a full-width month selector.
- One contextual mobile add action; no floating overlap.
- Mobile utility menu for Search, Productivity, Cloud Sync, and Appearance.
- Short mobile Money workspace labels.
- Two-column summaries on standard iPhones, one-column fallback below 371px.
- Collapsed mobile filters with active-filter counts.
- Centered Settings and Reports tabs with hidden native scrollbars.
- Minimum 44 × 44px visible mobile controls.

## Protected behavior
No finance formula, profile role, encryption function, Cloud Schema V3 record path, ledger rule, data migration, or protected rollback asset was changed.
