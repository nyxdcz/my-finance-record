# V12.18.8 Optional Gym Icon Validation

- New Gym expenses do not receive an emoji automatically.
- The Gym emoji remains available in the icon picker.
- Existing Gym icons are preserved during normalization and editing.
- Price, weekday, recurrence, and monthly-override changes do not restore the Gym emoji.
- A Gym expense can be saved with no icon.
- Schema version remains 12 and no data migration is required.
